Where this fits

In lecture, Gibbs sampling was derived as Metropolis-Hastings with acceptance probability one. For the zero-field Ising model,

\[ p(\mathbf{x}) \propto \exp\left(\beta\sum_{i\sim j}x_i x_j\right), \qquad x_i\in\{-1,+1\}, \]

the full conditional of one spin depends only on its neighbours:

\[ p(x_i=+1\mid\mathbf{x}_{-i})=\sigma(2\beta s_i), \qquad s_i=\sum_{j\sim i}x_j. \]

Today you will turn that equation into two samplers and determine whether their output is trustworthy.

Goals

  1. Implement Gibbs sampling one site at a time.
  2. Use conditional independence to update half the lattice simultaneously with block Gibbs.
  3. Validate both samplers against exact answers on a \(3\times3\) lattice.
  4. Diagnose dependent output using trace plots and multiple-chain split \(\hat R\).

Block Gibbs

Why a checkerboard block works

Colour the lattice like a checkerboard. Every neighbour of a dark site is light, and every neighbour of a light site is dark.

Given all light spins, the dark spins are conditionally independent:

\[ p(\mathbf{x}_{\mathrm{dark}}\mid\mathbf{x}_{\mathrm{light}}) =\prod_{i\in\mathrm{dark}}p(x_i\mid\mathbf{x}_{\mathrm{light}}). \]

We can therefore draw every dark spin simultaneously, then recompute the neighbour sums and draw every light spin simultaneously.

Dependent draws

A helper for running one chain

def run_trace(beta, n, burn, draws, rng, start=None):
    if start is None:
        x = rng.choice([-1, 1], size=(n, n))
    else:
        x = np.full((n, n), start, dtype=int)

    dark_mask = np.add.outer(np.arange(n), np.arange(n)) % 2 == 0
    for _ in range(burn):
        block_gibbs_sweep(x, beta, rng, dark_mask)

    trace = np.empty(draws)
    for t in range(draws):
        block_gibbs_sweep(x, beta, rng, dark_mask)
        trace[t] = x.mean()
    return trace

Multiple chains and \(\hat R\)

Why one chain is not enough

A trace can look stable because it is trapped in one region. Run several chains from deliberately different starting points.

  • If the chains explore the same target, their between-chain variation should eventually resemble their within-chain variation.
  • If chains remain separated, the between-chain variation is too large.
  • Agreement does not prove convergence, but disagreement is direct evidence of failure.

Split \(\hat R\)

Suppose each of the \(M\) original chains contains \(L\) draws. Split each chain in half, giving \(2M\) sequences of length \(T=\lfloor L/2\rfloor\). For split chain \(j\), let \(\bar f_j\) be its sample mean and \(s_j^2\) its sample variance. Let \(\operatorname{Var}(\bar f_1,\ldots,\bar f_{2M})\) denote the sample variance across the \(2M\) chain means. Then

\[ W=\frac{1}{2M}\sum_{j=1}^{2M}s_j^2, \qquad B=T\operatorname{Var}(\bar f_1,\ldots,\bar f_{2M}), \]

and

\[ \widehat{V}=\frac{T-1}{T}W+\frac{1}{T}B, \qquad \hat R=\sqrt{\frac{\widehat V}{W}}. \]

Values appreciably above one indicate that the chains do not yet agree.

What diagnostics can and cannot say

  • Split \(\hat R\) checks whether dispersed chains agree.

Backup slides

Why \(\hat R\) approaches one

Suppose every split chain has reached the same stationary distribution, with mean \(\mu\) and variance \(\sigma^2\).

  • The average within-chain variance estimates the target variance: \[W\approx\sigma^2.\]
  • As the chains run longer, their means concentrate near the same \(\mu\), so \[\frac{B}{T}=\operatorname{Var}(\bar f_1,\ldots,\bar f_{2M})\longrightarrow0.\]

Consequently,

\[ \widehat V=\frac{T-1}{T}W+\frac{1}{T}B\approx W, \qquad \hat R=\sqrt{\widehat V/W}\approx1. \]

For independent stationary draws, \(\operatorname{Var}(\bar f_j)=\sigma^2/T\), so \(B\approx\sigma^2\) and \(\hat R\approx1\) at any \(T\). For a chain with integrated autocorrelation time \(\tau\), \(\operatorname{Var}(\bar f_j)\approx\tau\sigma^2/T\), so \(B\approx\tau\sigma^2\) and

\[ \hat R\approx\sqrt{1+\frac{\tau-1}{T}}. \]

This is why \(\hat R\) stays slightly above one for a finite run even when every chain is stationary, and why it approaches one as \(T\) grows.

Why \(\hat R\) can be large

Suppose some chains are trapped near \(+1\) and others near \(-1\).

  • Each chain may fluctuate very little, making the within-chain variance \(W\) small.
  • The chain means are far apart, making the between-chain estimate \(B\) large.
  • Therefore \(\widehat V>W\) and \(\hat R>1\).

Splitting also compares the first and second halves of each chain, so a chain that is drifting can disagree with itself.

Important

\(\hat R\approx1\) means that the chains agree; it does not prove convergence. All chains could be trapped in the same mode.

Autocorrelation

For a scalar trace \(f_t=f(\mathbf{x}^{(t)})\), the lag-\(k\) autocorrelation measures how much knowing \(f_t\) predicts \(f_{t+k}\):

\[ \hat\rho_k= \frac{\sum_{t=1}^{N-k}(f_t-\bar f)(f_{t+k}-\bar f)} {\sum_{t=1}^{N}(f_t-\bar f)^2}, \qquad \hat\rho_0=1. \]

The direct implementation follows this expression literally:

def autocorrelation_direct(f, max_lag):
    z = np.asarray(f, dtype=float) - np.mean(f)
    denominator = np.dot(z, z)
    return np.array([
        np.dot(z[:len(z) - k], z[k:]) / denominator
        for k in range(max_lag + 1)
    ])

Computing \(K\) lags directly costs \(O(NK)\), which is fine when \(K\) is small.

Faster autocorrelation with the FFT

The FFT computes all \(N\) lags in \(O(N\log N)\) time:

def autocorrelation(f):
    z = np.asarray(f, dtype=float) - np.mean(f)
    n = len(z)
    F = np.fft.rfft(z, 2 * n)
    rho = np.fft.irfft(F * np.conj(F))[:n]
    return rho / rho[0]

direct = autocorrelation_direct(traces[0.3], max_lag=200)
fast = autocorrelation(traces[0.3])[:201]
print("maximum difference:", np.max(np.abs(direct - fast)))
maximum difference: 1.1102230246251565e-16

The two calculations agree; the FFT is only a computational shortcut. Slowly decaying \(\rho_k\) means that many recorded states contain nearly the same information.

Effective sample size

The integrated autocorrelation time and effective sample size for the function \(f\) are

\[ \tau_f=1+2\sum_{k=1}^{\infty}\rho_k, \qquad \operatorname{ESS}_f=\frac{N}{\tau_f}. \]

An average of \(N\) dependent draws has approximately the same Monte Carlo error as an average of \(\operatorname{ESS}_f\) independent draws.

Note

ESS belongs to a function and a chain. The same states may give a large ESS for a local statistic and a small ESS for magnetization.

Geyer’s initial positive sequence

At large lags, estimated autocorrelations are mostly noise. For a reversible Markov chain, Geyer groups adjacent autocorrelations into

\[ \widehat G_k=\hat\rho_{2k}+\hat\rho_{2k+1}, \qquad k=0,1,\ldots \]

Starting with \(k=0\), keep the longest initial sequence for which every \(\widehat G_k>0\); stop before the first nonpositive pair. If \(m\) is the final retained index, estimate

\[ \hat\tau_f=-1+2\sum_{k=0}^{m}\widehat G_k, \qquad \widehat{\operatorname{ESS}}_f=\frac{N}{\hat\tau_f}. \]

This is the initial positive sequence estimator of Geyer (1992), “Practical Markov Chain Monte Carlo,” Statistical Science 7(4): 473–483.

Note

Geyer’s positivity result is for reversible chains. A fixed dark-then-light Gibbs sweep leaves \(p\) invariant but need not itself be reversible; the estimator is included here as a common reference method, not as a required diagnostic for this lab.

def ess(f):
    rho = autocorrelation(f)
    tau = -1.0

        pair = rho[k] + rho[k + 1]
        if pair <= 0:
            break
        tau += 2 * pair
    return len(f) / tau
