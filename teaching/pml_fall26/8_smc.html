Importance sampling

Bayesian inference

Posterior distribution of the hidden variable \(z \in \mathcal{Z}\) given we observe \(y \in \mathcal{Y}\):

\[ p(z \mid y) = \frac{p(y \mid z) \, p(z)}{p(y)} \]

  • \(p(y \mid z)\): data likelihood.
  • \(p(z)\): prior distribution.
  • \(p(y)\): marginal likelihood.

Goal

Compute the expectation of a function \(h\) with respect to the posterior distribution:

\[ I = \mathbb{E}_{p(z \mid y)}[h(z)] = \int h(z) \, p(z \mid y) \, dz, \]

where \(h\) is a known function that we can evaluate.

Examples

Example 1: \(h(z) = z\),

\[ \mathbb{E}_{p(z \mid y)}[z] = \int z \, p(z \mid y) \, dz. \]

Example 2: \(h(z) = 1[z > a]\) for \(z, a \in \mathbb{R}\),

\[ \mathbb{E}_{p(z \mid y)}\big[1[z > a]\big] = P(z > a \mid y) = \int 1[z > a] \, p(z \mid y) \, dz. \]

Solution I: Monte Carlo

If \(p(z \mid y)\) is a known distribution such as the Normal distribution, we can use a Monte Carlo approximation to compute the expectation no matter how complex \(h\) is:

\[ \frac{1}{N} \sum_{i=1}^{N} h(z^i) \xrightarrow{\text{a.s.}} \mathbb{E}_{p(z \mid y)}[h(z)] \text{ where } z^i \overset{\text{iid}}{\sim} p(z \mid y), \text{ as } N \to \infty, \]

by the strong Law of Large Numbers (LLN), provided \(\mathbb{E}_{p(z \mid y)}|h(z)| < \infty\).

Reality…

  • In many cases, the integral \(p(y) = \int p(z, y) \, dz\) is not analytically available.
  • Hence, \(p(z \mid y)\) is not known in practice.

An important exception is if the likelihood and prior are conjugate distributions. In this case, \(p(z \mid y)\) is known and can be sampled from.

Solution II: Importance sampling

  • Find a distribution \(q\) that is easy to sample from and \(q(z) > 0\) whenever \(p(z \mid y) > 0\).
  • Propose \(z^i \sim q(z)\) for \(i = 1, \ldots, N\).
  • Let \(w(z) = p(z \mid y) / q(z)\). Then, \[ \frac{1}{N} \sum_{i=1}^{N} w(z^i) \, h(z^i) \xrightarrow{\text{a.s.}} I, \] by LLN.

Derivation

\[ \begin{aligned} I &= \int h(z) \, p(z \mid y) \, dz \\ &= \int h(z) \frac{p(z \mid y)}{q(z)} q(z) \, dz \\ &= \int h(z) \, w(z) \, q(z) \, dz \\ &= \mathbb{E}_{q}[h(z) \, w(z)]. \end{aligned} \]

Therefore, importance sampling is a Monte Carlo algorithm that approximates the expectation with respect to \(q\) with test function \(h'(z) = h(z) \, w(z)\).

Self normalization

Problem: we assumed that \(p(z \mid y)\) can be evaluated. However, this requires computing \(p(y)\),

\[ p(y) = \int p(y \mid z) \, p(z) \, dz, \]

which is intractable in many settings. Therefore, \(p(z \mid y) = p(z, y) / p(y)\) cannot be evaluated.

Self normalization

  • Let \(\gamma(z) = p(z, y) = p(y \mid z) \, p(z)\) and \(Z = p(y)\), so \(p(z \mid y) = \gamma(z) / Z\).
  • Use the unnormalized weight function, which we can evaluate: \(w(z) = \frac{\gamma(z)}{q(z)} = Z \, \frac{p(z \mid y)}{q(z)}\).
  • Normalize: \(\bar{w}^i = \frac{w(z^i)}{\sum_j w(z^j)}\). The unknown \(Z\) multiplies every weight, so it cancels.

Then,

\[ \sum_{i=1}^{N} \bar{w}^i \, h(z^i) \xrightarrow{\text{a.s.}} I. \]

Proof sketch

Write the estimator as a ratio of two sample averages:

\[ \sum_{i=1}^{N} \bar{w}^i \, h(z^i) = \frac{\sum_{i=1}^{N} w(z^i) \, h(z^i)}{\sum_{j=1}^{N} w(z^j)} = \frac{A_N}{B_N}, \]

where

\[ A_N = \frac{1}{N} \sum_{i=1}^{N} h(z^i) \frac{\gamma(z^i)}{q(z^i)}, \qquad B_N = \frac{1}{N} \sum_{i=1}^{N} \frac{\gamma(z^i)}{q(z^i)}. \]

Each is an ordinary Monte Carlo average under \(q\), so the LLN applies to each separately.

Proof sketch: numerator

By LLN, the numerator converges to \(\int h(z) \, p(z, y) \, dz\):

\[ A_N \xrightarrow{\text{a.s.}} \mathbb{E}_{q}\left[\frac{h(z) \, \gamma(z)}{q(z)}\right], \]

\[ \begin{aligned} \text{RHS} &= \int h(z) \frac{\gamma(z)}{q(z)} q(z) \, dz \\ &= \int h(z) \, \gamma(z) \, dz \\ &= \int h(z) \, p(z, y) \, dz. \end{aligned} \]

Proof sketch: denominator

The denominator converges to \(Z = p(y)\):

\[ B_N \xrightarrow{\text{a.s.}} \mathbb{E}_{q}\left[\frac{\gamma(z)}{q(z)}\right], \]

\[ \begin{aligned} \text{RHS} &= \int \frac{\gamma(z)}{q(z)} q(z) \, dz \\ &= \int p(z, y) \, dz \\ &= p(y). \end{aligned} \]

Proof sketch: from two limits to the ratio

We know \(A_N \to a := \int h(z) \, \gamma(z) \, dz\) and \(B_N \to Z\) separately. Does \(A_N / B_N \to a / Z\)?

  • Not automatically: a ratio of convergent sequences can misbehave if the denominator’s limit is \(0\).
  • The tool that settles it is the continuous mapping theorem: continuous functions preserve limits of random variables.

The continuous mapping theorem

Theorem (van der Vaart, 1998, Thm 2.3). Let \(W_1, W_2, \ldots\) and \(W\) be random vectors in \(\mathbb{R}^d\). Let \(g : \mathbb{R}^d \to \mathbb{R}^m\) be continuous at every point of a set \(C\) with \(P(W \in C) = 1\). Then

  • if \(W_N \xrightarrow{\text{a.s.}} W\), then \(g(W_N) \xrightarrow{\text{a.s.}} g(W)\);
  • if \(W_N \xrightarrow{p} W\), then \(g(W_N) \xrightarrow{p} g(W)\);
  • if \(W_N \xrightarrow{d} W\), then \(g(W_N) \xrightarrow{d} g(W)\).

In words: \(g\) may be discontinuous somewhere, as long as the limit \(W\) lands there with probability zero.

Applying it

  • The random vector. \(W_N = (A_N, B_N) \in \mathbb{R}^2\). Both coordinates converge almost surely, so the vector does: \(W_N \xrightarrow{\text{a.s.}} W = (a, Z)\), a constant.
  • The function. \(g(u, v) = u / v\). It is continuous on \(C = \{(u, v) : v \neq 0\}\).
  • The condition. \(Z = p(y) > 0\), so \(P(W \in C) = 1\).

Therefore

\[ \sum_{i=1}^{N} \bar{w}^i \, h(z^i) = g(A_N, B_N) \xrightarrow{\text{a.s.}} g(a, Z) = \frac{\int h(z) \, p(z, y) \, dz}{p(y)} = \int h(z) \, p(z \mid y) \, dz = I. \]

The LLN steps require \(\mathbb{E}_{p(z \mid y)}|h(z)| < \infty\) and \(q(z) > 0\) wherever \(\gamma(z) > 0\).

Estimating the marginal likelihood

The denominator \(B_N\) is itself an estimator of \(Z = p(y)\):

\[ \hat{Z} = \frac{1}{N} \sum_{i=1}^{N} w(z^i), \qquad w(z) = \frac{\gamma(z)}{q(z)}. \]

  • Consistent: \(\hat{Z} \xrightarrow{\text{a.s.}} Z\), shown on the previous slides.
  • Unbiased, for every \(N\): \[ \mathbb{E}[\hat{Z}] = \frac{1}{N} \sum_{i=1}^{N} \mathbb{E}_q[w(z^i)] = \int \frac{\gamma(z)}{q(z)} q(z) \, dz = Z. \]

The self-normalized estimate of \(I\) is a ratio, and it is biased for finite \(N\). \(\hat{Z}\) is not a ratio, so it has no such bias.

Example: small tail probabilities

Adapted from Robert and Casella (2013, Example 3.11), which uses an exponential shifted to start at \(4.5\). Importance sampling can be useful in many settings beyond Bayesian statistics.

Let \(X \sim N(0, 1)\), with density \(\varphi\). Estimate \(P(X > 4.5)\).

  • Solution 1: \(x^i \sim N(0, 1)\). Compute \[ \frac{1}{N} \sum_i 1[x^i > 4.5]. \]
  • Solution 2: \(x^i \sim q\), the exponential distribution with rate \(0.1\) (mean \(10\)), \(q(x) = 0.1 \, e^{-0.1 x}\) for \(x > 0\). Compute \[ \frac{1}{N} \sum_i 1[x^i > 4.5] \frac{\varphi(x^i)}{q(x^i)}. \]

Note: we need to choose \(q\) to cover the region of interest (i.e., \(x\) for which \(h(x) \, \varphi(x) > 0\)).

Example: small tail probabilities

The region \(x > 4.5\) (shaded) has probability \(3.4 \times 10^{-6}\) under \(\varphi\), but 0.64 under \(q\): most proposals from \(q\) land where \(h(x) = 1\).

Example: small tail probabilities

Estimates of \(P(X > 4.5) = 3.4 \times 10^{-6}\), with fresh samples for each \(N\). Monte Carlo from \(\varphi\) returns exactly \(0\) until \(N\) is large enough to see a single draw above \(4.5\), and is noisy after that: a single hit at \(N = 10^5\) gives \(10^{-5}\), three times the truth. Importance sampling is on target from \(N = 10^3\).

Brief summary

  • Monte Carlo approximates integrals by averages, but needs samples from \(p(z \mid y)\).
  • Importance sampling draws from an easy \(q\) instead and reweights. It needs \(q(z) > 0\) wherever \(h(z) \, p(z \mid y) \neq 0\).
  • One set of weights, three estimators:
    • IS for \(I\), with \(w = p(z \mid y) / q\): unbiased, but needs the normalized posterior.
    • Self-normalized IS for \(I\), with \(w = \gamma / q\): needs only \(\gamma\). Consistent (LLN plus the continuous mapping theorem), but biased for finite \(N\), with bias of order \(1/N\).
    • \(\hat{Z} = \frac{1}{N} \sum_i w(z^i)\) for the marginal likelihood \(Z = p(y)\): unbiased for every \(N\).
  • A good \(q\) depends on what we estimate, not only on \(p(z \mid y)\). In the tail example, a \(q\) that puts its mass where \(h(x) \, \varphi(x)\) is large beats sampling from \(\varphi\) itself by orders of magnitude. The variance-minimizing choice is \(q^*(z) \propto |h(z)| \, p(z \mid y)\) (Robert and Casella, 2013, Thm 3.12).
  • \(q\) needs tails at least as heavy as \(p(z \mid y)\), or the weights can have infinite variance (next lecture).

Sequential importance sampling

Sequential importance sampling

Now, let \(\boldsymbol{z} = (z_1, \ldots, z_T)\) be a \(T\)-dimensional vector.

Goal: compute

\[ I = \int h(z_1, \ldots, z_T) \, p(z_1, \ldots, z_T \mid \boldsymbol{y}) \, dz_1 \cdots dz_T. \]

  • Solution I: importance sampling. We need to find a multivariate proposal distribution that is easy to sample from.
  • If \(z_t \in \mathbb{R}\), we may be able to use a multivariate Normal distribution. But for a general setting, finding \(q\) may be difficult.
  • Also, the curse of dimensionality: the number of samples needed to sufficiently approximate the integral grows exponentially with dimension.

One dimension at a time

Idea: propose one dimension at a time from \(z_t \sim q_t(\cdot \mid z_{1:t-1})\) for \(t = 1, \ldots, T\).

Choose a sequence of unnormalized intermediate targets \(\gamma_t(z_{1:t})\), one per dimension, ending at the target of interest: \(\gamma_T = \gamma\).

Proposal \(z_t^i \sim q_t(\cdot \mid z_{1:t-1}^i)\)
Sample extension \(z_{1:t}^i = (z_{1:t-1}^i, z_t^i)\)
Weight computation \(w(z_{1:t}^i) = \dfrac{\gamma_t(z_{1:t}^i)}{\nu_t(z_{1:t}^i)}\)

where \(\nu_{t}(z_{1:t}) = \prod_{s=1}^t q_s(z_s \mid z_{1:s-1})\) is the proposal density of the first \(t\) coordinates, and \(z_{s:t} = (z_s, \ldots, z_t)\) for \(s \le t\).

The superscript \(i = 1, \ldots, N\) indexes the samples, which we call particles. We write \(N\) for the number of particles.

Application: state-space models

\[ \begin{aligned} z_1 &\sim \mu(z_1) \\ z_t \mid z_{t-1} &\sim f(z_t \mid z_{t-1}) \text{ for } t = 2, \ldots, T \\ y_t \mid z_t &\sim g(y_t \mid z_t) \text{ for } t = 1, \ldots, T. \end{aligned} \]

State-space model: the same graph as in the HMM lecture, but the hidden state \(z_t\) may be continuous. The HMM is the special case with discrete \(z_t \in \{1, \ldots, K\}\). \(\mu\) plays the role of \(\pi\), the initial distribution, \(f\) of the transition matrix \(A\), and \(g\) of the emission distribution \(p(y_t \mid \phi_{z_t})\). The emissions can be discrete or continuous in either case. The SMC literature (e.g., Doucet and Johansen, 2009) often calls a state-space model a (general) hidden Markov model.

Application: state-space models

  • \(p(\boldsymbol{z}) = \mu(z_1) \prod_{t=2}^{T} f(z_t \mid z_{t-1})\)
  • \(p(\boldsymbol{y} \mid \boldsymbol{z}) = \prod_{t=1}^{T} g(y_t \mid z_t)\)
  • \(\gamma(\boldsymbol{z}) = p(\boldsymbol{z}, \boldsymbol{y}) = \mu(z_1) \, g(y_1 \mid z_1) \prod_{t=2}^{T} f(z_t \mid z_{t-1}) \, g(y_t \mid z_t)\).
  • \(Z = p(\boldsymbol{y}) = \int p(\boldsymbol{z}, \boldsymbol{y}) \, d\boldsymbol{z}\)

The natural intermediate targets use the data seen so far:

\[ \gamma_t(z_{1:t}) = p(z_{1:t}, y_{1:t}) = \mu(z_1) \, g(y_1 \mid z_1) \prod_{s=2}^{t} f(z_s \mid z_{s-1}) \, g(y_s \mid z_s), \qquad \gamma_T = \gamma. \]

Recursive weight update

\[ \begin{aligned} w(z_{1:t}) &= \frac{\gamma_t(z_{1:t})}{\nu_{t}(z_{1:t})} \\ &= \frac{\gamma_{t-1}(z_{1:t-1})}{\nu_{t-1}(z_{1:t-1})} \frac{f(z_t \mid z_{t-1}) \, g(y_t \mid z_t)}{q_t(z_t \mid z_{1:t-1})} \\ &= w(z_{1:t-1}) \, \alpha(z_{1:t-1}, z_t). \end{aligned} \]

At \(t = 1\): \(w(z_1) = \mu(z_1) \, g(y_1 \mid z_1) / q_1(z_1)\).

Therefore, we should store the weight from the previous iteration and compute only the weight update function \(\alpha(z_{1:t-1}, z_t)\) at the current iteration.

Proposal

  • Prior: \(q_t = f(z_t \mid z_{t-1})\).
    • Weight function: \(\alpha(z_{1:t-1}, z_t) = g(y_t \mid z_t)\).
    • Pro: simplicity.
    • Con: may require a large number of samples if \(f(z_t \mid z_{t-1})\) differs significantly from \(p(z_t \mid z_{t-1}, y_t)\), i.e., when \(y_t\) is informative about \(z_t\).

Proposal

Adapted: \(q_t = p(z_t \mid z_{t-1}, y_t)\). By the Markov property, conditioning on \(z_{1:t-1}\) is the same as conditioning on \(z_{t-1}\).

\[ p(z_t \mid z_{t-1}, y_t) = \frac{g(y_t \mid z_t) \, f(z_t \mid z_{t-1})}{p(y_t \mid z_{t-1})}, \qquad p(y_t \mid z_{t-1}) = \int g(y_t \mid z_t) \, f(z_t \mid z_{t-1}) \, dz_t. \]

Weight update function:

\[ \alpha(z_{1:t-1}, z_t) = \frac{f(z_t \mid z_{t-1}) \, g(y_t \mid z_t)}{p(z_t \mid z_{t-1}, y_t)} = p(y_t \mid z_{t-1}), \]

which does not depend on the newly proposed \(z_t\).

  • Pro: makes use of the latest observation to build a smart proposal. Generally requires fewer samples than the prior proposal (for example, to attain similar accuracy of approximation).
  • Con: need to both sample from \(p(z_t \mid z_{t-1}, y_t)\) and evaluate \(p(y_t \mid z_{t-1})\) analytically. This is possible only for special models (e.g., linear-Gaussian \(f\) and \(g\)).

Example: stochastic volatility model

\[ \begin{aligned} z_1 &\sim \mathcal{N}(0, \sigma^2) \\ z_t \mid z_{t-1} &\sim \mathcal{N}(\phi z_{t-1}, \sigma^2), & t &= 2, \ldots, T, \\ y_t \mid z_t &\sim \mathcal{N}(0, \beta^2 \exp(z_t)), & t &= 1, \ldots, T. \end{aligned} \]

  • \(z_t\): unobserved log-volatility of an asset (e.g., a stock).
  • \(y_t\): observed log-return of the asset, whose variance is \(\beta^2 \exp(z_t)\).

In the examples: \(\phi = 1\) (a random walk), \(\sigma = 0.16\), \(\beta = 0.64\), \(T = 100\).

Example: stochastic volatility model

Top: the hidden log-volatility \(z_t\) and the observation variance \(\beta^2 \exp(z_t)\). Bottom: the observations \(y_t\), which spread out where the variance is large.

Weight degeneracy

Left: one particle’s normalized weight stays near \(1\) (log weight near \(0\)) while the others fall by orders of magnitude. Right: the effective sample size \(\text{ESS}_t = 1 / \sum_i (\bar{w}_t^i)^2\) collapses. It is \(N\) when all weights are equal and \(1\) when one particle has all the weight. Here it towards \(1\) particle.

Brief summary

  • SIS was originally designed for settings where we need to approximate a high-dimensional integral or perform imputation (Kong, Liu and Wong, JASA, 1994).
  • Particularly useful if the model exhibits a temporal structure.
  • Only need to find local (low-dimensional) proposal distributions.
  • Weights decay with \(T\). For large \(T\), SIS usually does not work well (contradictory to the first point).
  • Only a handful of samples remain relevant as \(T\) increases, wasting computational resources.
  • \(\hat{Z}_T^{\text{SIS}}\) is unbiased, but its relative variance typically grows exponentially in \(T\) (next lecture).

Sequential Monte Carlo

SIS with resampling

  • Idea: interleave a resampling step to choose promising particles.
  • Use the weights to prune the particles.
  • Sequential Monte Carlo methods refer to a class of algorithms that involve sequential proposal, weight computation, followed by (optional) resampling.
  • Best tutorial to get started in SMC (in my opinion): Doucet and Johansen (2009).

The algorithm

\(t = 1\), for each \(i = 1, \ldots, N\):

  • Proposal: \(z_1^i \sim q_1(z_1)\).
  • Weight computation: \(w_1^i = \mu(z_1^i) \, g(y_1 \mid z_1^i) / q_1(z_1^i)\).
  • Weight normalization: \(\bar{w}_1^i = w_1^i / \sum_{j} w_1^{j}\).

\(t \geq 2\), for each \(i = 1, \ldots, N\) independently:

  • Resampling: draw an ancestor index \(a_{t-1}^i \sim \text{Categorical}(\bar{w}_{t-1}^1, \ldots, \bar{w}_{t-1}^N)\).
  • Proposal: \(z_t^i \sim q_t(z_t \mid z_{1:t-1}^{a_{t-1}^i})\).
  • Extension: \(z_{1:t}^i = (z_{1:t-1}^{a_{t-1}^i}, z_t^i)\).
  • Weight computation: \(w_t^i = \alpha(z_{1:t-1}^{a_{t-1}^i}, z_t^i)\). Only the incremental weight: resampling has already accounted for the old weights.
  • Normalize the weights: \(\bar{w}_{t}^i = w_t^i / \sum_{j} w_t^{j}\).

With the prior proposal \(q_t = f\) (so \(\alpha = g\)) and resampling at every step, this is the bootstrap particle filter (Gordon, Salmond and Smith, 1993).

SMC on the same data with \(N = 10\) particles, the prior proposal, and multinomial resampling at every step. Same frames as for SIS. Grey: lines that died out. Red: the true hidden states.

SIS and SMC after 50 steps

  • SIS: prior random walks that never see the data drift away from the truth. The weight piles onto one of them (weight degeneracy).
  • SMC: resampling keeps the particles where the data put the hidden state, and the weights stay balanced. The price: traced back, the current particles share one ancestor for most of the path (path degeneracy).

Filtering

Samples and weights can be used to approximate the filtering distribution:

\[ \hat{p}(z_t \mid y_{1:t}) = \sum_{i=1}^{N} \bar{w}_t^i \, \delta_{z_t^i}(z_t) \text{ for } t = 1, \ldots, T, \]

or after resampling:

\[ \hat{p}(z_t \mid y_{1:t}) = \frac{1}{N} \sum_{i=1}^{N} \delta_{z_t^i}(z_t) \text{ for } t = 1, \ldots, T. \]

Effectiveness of SMC on the SV model

10,000 particles. At each \(t\), a pointwise 95% credible interval for \(z_t\) from \(\hat{p}(z_t \mid y_{1:t})\). The intervals contain the true \(z_t\) at 88% of the time points.

Predictive distribution

The generated samples can be used to build a predictive distribution:

\[ p(z_{t+1} \mid y_{1:t}) = \int f(z_{t+1} \mid z_t) \, p(z_t \mid y_{1:t}) \, dz_t. \]

For a fixed value of \(z_{t+1}\), this is an expectation under the filtering distribution with test function \(h(z_t) = f(z_{t+1} \mid z_t)\). Plugging in the particle approximation,

\[ \hat{p}(z_{t+1} \mid y_{1:t}) = \sum_{i=1}^{N} \bar{w}_t^i \, f(z_{t+1} \mid z_t^i), \qquad t = 1, \ldots, T-1, \]

a mixture of \(N\) transition densities. To sample from it: draw \(i \sim \text{Categorical}(\bar{w}_t^{1:N})\), then \(z_{t+1} \sim f(\cdot \mid z_t^i)\).

Wrapping up

Applications

  • Online estimation: as the observations arrive, infer the latent state.
    • E.g., fraud detection, missile tracking, robot localization, etc.
  • An extension of SMC (Del Moral, Doucet and Jasra, 2006) can be used in problems that do not exhibit temporal structure.
    • Phylogenetic inference (Bouchard-Côté, Sankararaman and Jordan, 2012).
    • Graph matching (Jun et al., 2017).
  • Inference over graphical models (Naesseth, Lindsten and Schön, 2014).
  • Probabilistic programming (Murray et al., 2017).
